# SmartCampus AI — Prompt Wars Prototype

This is the first frontend prototype for the Smart Campus Solutions track.

## Current features
- Landing page
- AI Campus Assistant with demo responses
- Smart Campus Issue Report form
- Notices section
- Mobile responsive layout

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For the next version, connect the chatbot to an AI API and add a campus knowledge base.

## Hackathon direction
The final project should demonstrate:
Student -> AI Assistant -> Campus information / Issue understanding -> Useful action.

Do not put real API keys in frontend JavaScript.
